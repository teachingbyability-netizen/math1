📝 【任務題目】
某校有男生 0 人、女生 0 人，將男女生分別編隊，每隊人數要相等，且隊數要最少。
請問共可編幾隊？每隊有幾人？

第一關：破解「每隊人數相等」

題目說：既然要分組，而且每隊人數要「剛好一樣多」，代表這個人數必須能同時整除 0 和 0。

你覺得我們應該找這兩個數字的什麼？

第二關：村長的考驗

題目還給了一個超重要條件：「隊數要最少」。

想像一下，如果想管理最少的隊伍，那每一隊裡面應該要塞「很多人」還是「很少人」？

第三關：魔王的陷阱

結合前兩關，我們知道要找 0 和 0 的「最大公因數」。利用短除法算出來是 0。

陷阱來了：算出來的這個 0，單位到底是什麼？

最終關：擊敗魔王

既然知道「每隊有 0 人」，那我們來算總隊數吧！請填寫正確的數字：
男生隊數：0 ÷ 0 = 隊
女生隊數：0 ÷ 0 = 隊
總共隊伍 = 隊

🎉 挑戰成功！

太棒了！你完美破解了任務！

解題口訣：
平分相同找因數，隊伍最少找最大！
算出單位別弄錯，最後除完再相加！
